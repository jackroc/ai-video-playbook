# REF-001 · 保留机制，重写人货场

- 生成验证：**待验证；这是改编流程模板，尚无外部参考或实际输出**
- 带货效果：未测
- 创建日期：2026-11-03
- 类型：参考视频拆解 / 创意改编
- 设计：约 24–30 秒，按选定参考和商品重写
- 模型 / 参数 / 任务 ID / 实验 / 成片：尚未选择或产生

## 什么时候用

已经找到喜欢的视频，希望借鉴它的信息差、冲突升级或动作节拍，并让自己的商品成为剧情必要的一环。先拆解创意机制，再制作新脚本。

## 第一步：输入真实观察

用 [参考模板](../../templates/reference.md) 写明作者、链接、观看范围和关键时间码。无法观看时请注明，仅凭标题不能写逐镜拆解。

```text
原视频链接：待补
开头发生的事：待补
观众先知道什么、后知道什么：待补
主要笑点及对应时间码：待补
商品在原视频中做了什么：待补
可迁移机制：待补
不能直接复用的素材或表达：待补
```

## 第二步：先生成脚本方案

下面是给文本模型的策划提示词，不是直接提交给视频模型的镜头提示词。填好占位符后使用。

```text
请根据以下资料创作一个新的商品短视频方案，输出中文分析和逐镜脚本。

【商品事实】
商品与变体：[填写]
真实外观、尺寸、使用步骤：[填写]
有依据的卖点与不能宣称的内容：[填写]
可用的人物和场景素材：[填写]
目标市场、语言、画幅、时长：[填写]

【实际观看的参考拆解】
来源、观看范围、时间码：[填写]
观察到的冲突、信息差、反转和节拍：[填写]
需要保留的创意机制：[填写]

请给出两套可选脚本：
A. 保留核心机制，重写人物、商品、地点、对白和具体动作。
B. 保留一个核心动作或笑点，新增开头动机与结尾回扣。

每套写出一句话概念、观众为什么继续看、商品为什么不可缺少、
逐镜时间设计、主动作、商品露出、声音和结束状态。
总时长匹配目标；每个生成镜头只安排一个主要动作。
真实功能演示与超现实笑点分镜处理。
列出所需素材、可能生成失败的镜头和可用的简化方案。
缺少商品事实时标记待补，不补造功能、评价或效果数据。
不声称改编后必然爆款，不复制原作者的独特台词或原始视频素材。
```

## 第三步：选定一套，转成逐镜提示词

```text
将下面已选定的脚本转换成视频生成的镜头提示词。
已选脚本：[粘贴完整脚本]
素材 ID 与实际素材用途：[填写]
平台 / 模型 / 支持的输入与单段时长：[实际核对后填写]
画幅、输出语言和音频策略：[填写]

逐镜输出：
1. 镜头编号与计划时长；
2. 需要绑定的真实素材；
3. 完整提示词：景别、机位、光线、主体、单一主动作、表演、声音、结束状态；
4. 必须保留的商品事实与连续性；
5. 后期字幕、配音或合成步骤；
6. 本镜的验收条件和失败后的最小简化。

素材 ID 仅作映射，不当作平台特殊语法。
模型不支持的能力明确标出，并给出实际可执行的替代步骤。
```

## 第四步：实测后成为独立方案

给最终脚本分配新 ID，按 [方案模板](../../templates/playbook.md) 保存完整镜头提示词。先测试核心动作，再生成前后镜头；每轮使用 [实验模板](../../templates/experiment.md) 留证。不要把这套策划模板本身标成成片已验证。

如果商品只是被摆在画面边缘，而剧情和结果完全不依赖它，返回第二步，重新建立商品与冲突的关系。
