# 验证、评分和效果证据

以下是本仓库自己的收录标准，用来统一记录，不代表行业统计结论。

## 生成验证状态

| 状态 | 最低证据 |
| --- | --- |
| 待验证 | 只有构思、脚本或提示词，没有可检查的实际输出 |
| 测试中 | 已有生成记录，尚未满足验收要求 |
| 已验证 | 至少一条完整成片通过本页验收，并保存输入、完整提示词、参数、原始片段与后期步骤 |
| 可复现 | 在明确记录的相同条件下，至少 3 次独立完整尝试中有 2 次通过；列出全部结果 |
| 暂不推荐 | 实测缺陷或成本不适合当前目标；写清适用边界和复查条件 |

模型、商品或输入工作流变更时重新测试。视频链接失效或关键复现资料缺失时，将证据状态标为待补，不能继续据此推荐。

## 成片验收

逐项记录 1–5 分并附具体镜头依据。1 为明显失败，3 为基本可用，5 为符合目标且无明显问题；无法判断写未测。

| 维度 | 看什么 |
| --- | --- |
| 商品一致性 | 外形、尺寸、变体、标志、配件、用法是否准确 |
| 动作可读性 | 观众能否看清发生了什么，接触、受力和结果是否连续 |
| 人物与场景连续性 | 身份、服装、道具位置、光线是否衔接 |
| 叙事与创意 | 开头是否建立问题，商品是否推动结果，反转是否能理解 |
| 声画质量 | 口型、噪声、字幕、剪辑和画面缺陷是否影响观看 |
| 复用成本 | 重试、花费和后期工作量是否在项目预算内 |

本库把前 5 项均达到 3 分且没有错误商品、虚构功能或不可理解关键动作的成片视为通过；成本单独报告。不用平均分掩盖商品错误。

## 带货效果单独记

可用状态：未测 / 有观察数据 / 有对照实验 / 证据待补。

记录平台、市场、时间窗、自然流量或付费流量、样本量、投放费用、目标人群、商品价格、优惠、点击、订单与退款口径。保留来源或经过脱敏的截图；每个比率写明分子与分母。

单条视频有播放量不能推导为方案能提升转化。对照实验尽量只变一个主要因素，并记录剩余差异；没有足够证据时只陈述观察，不写「爆款」「高转化已证明」。
