# 从商品资料到成片

## 1. 写清输入

记录商品链接、具体变体、商品多角度图、尺寸、实际用法、可宣称卖点、目标受众、语言、画幅和预算。人物出镜时准备可使用的人物素材；缺项写「待补」，不要补造事实。

## 2. 选择叙事机制

先写一句话：`主角遇到什么问题 → 商品如何改变动作或结果 → 结尾为什么值得看`。选择 UGC、搞笑或演示方案，写出开头、商品露出、真实使用和结尾。先确认商品在剧情中的必要性。

## 3. 拆镜头与资产

每镜指定主动作、商品位置、人物衣着、时长设计和结束状态。复杂手部接触、商品特写、超现实场景分别制作。准备素材清单，并标明哪些是原图、哪些是生成图、哪些需要后期合成。

## 4. 选择并记录生成方式

按镜头需要选择文生视频、图生视频或实际可用的参考视频工作流。记录平台、模型完整名称与版本、日期、时长、分辨率、比例、种子（若提供）、参考素材映射和所有设置。模型不支持的设置写「不支持」，不要填写假值。

先测试最容易失败的镜头，例如手和商品接触的功能演示。它能通过后，再生成其余镜头。

## 5. 生成、验收、局部修复

逐镜检查商品、人物、动作因果、连续性和声音。失败时保留原文件，按 [排错页](troubleshooting.md) 改一个主要变量重试。若使用真实商品图合成，也必须记录合成步骤。

## 6. 剪辑与输出

用剪辑完成镜头时长、节拍、旁白、字幕、音效和 CTA。字幕与商品信息核对；保持商品展示可辨认。导出设置、音乐与素材来源一并保存。

## 7. 归档与复测

使用 [实验模板](../templates/experiment.md) 记录全部尝试，包括失败数、可用数、成本和后期耗时。保存原始生成片段和最终成片的长期链接。达到 [验证条件](evaluation.md) 后再更新 [方案目录](../CATALOG.md)。

建议一次实验目录包含：`record.md`、`prompt-v1.txt`、`prompt-v2.txt`、输入素材清单、原始输出链接和最终成片链接。不要只保留最终成功的一次。
