# 常见失败与修复实验

下列是待验证的修复方向。先确定故障发生在哪一镜，再做最小修改，并在实验中记录前后结果。

| 问题 | 先检查 | 下一次只改一件事 |
| --- | --- | --- |
| 商品变形或变色 | 是否混用了多个变体、参考图角度是否明确 | 换成单一变体、清晰角度的参考图 |
| 手指和商品穿模 | 动作是否同时包含抓取、旋转、开合等多步 | 拆出只有一次接触的近景 |
| 人物跨镜头换脸 | 是否每镜都绑定同一参考、衣着描述是否冲突 | 统一人物参考与衣着描述 |
| 画面漂亮但看不懂 | 是否缺少动作开始或结束状态 | 补一个展示操作结果的固定镜头 |
| 口播像念稿 | 句子是否过长、动作是否抢对白节拍 | 缩短为一句话，并标记停顿 |
| 口型不匹配 | 模型是否支持所需语言和音频工作流 | 测试短句口型镜头，或转为画外音 |
| 商品字样乱码 | 包装文字是否必须近距离可读 | 改用真实商品图并记录合成方式 |
| 笑点有了但商品不重要 | 拿掉商品后剧情是否依然成立 | 让解决问题的关键动作依赖商品真实功能 |
| 多镜头接不上 | 上镜末帧与下镜首帧位置是否冲突 | 明确两镜的手、商品位置和视线方向 |
| 开头拖沓 | 是否先讲背景才出现问题 | 把第一镜改成问题已经发生的瞬间 |

保存失败视频、修改前后提示词、参数和本次唯一主要变量。如果换了模型、素材和提示词，应记录为新的组合实验，不能只归因于一句提示词。
