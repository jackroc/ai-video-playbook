# 收录与检索

这个项目为商品创意选片积累可复用线索。商品分类帮助找同类，创意机制、动作与接入假设帮助跨品类寻找参考。具体商品的设计、尺寸、操作和款色适配需要在本次使用时核对。

## 数据与页面

`data/references.json` 是案例的统一数据源，每条有稳定 ID。首页双列卡片、创意机制索引和本轮收录清单由它生成。此前两批 Markdown 清单保留为历史记录。

[优先20条动作与换品分析](../references/2026-11-06-priority-20-analysis.md)也从该数据生成。首页对应卡片和机制索引均可直达单条分析。

[精选100动作与换品手册](../references/2026-11-06-curated-100.md)提供总览与按商品分类的详解，全部由同一数据生成。`curation`保存阅读顺序、入选理由、参考类型、详情位置及是否复用既有分析。

```bash
python3 scripts/reference_catalog.py validate
python3 scripts/reference_catalog.py render
python3 scripts/reference_catalog.py render --check
```

`validate` 检查字段、ID、媒体去重和本地链接。`render --check` 检查生成页面是否与数据一致。命令只使用 Python 标准库。

## 按动作和机制查询

```bash
python3 scripts/reference_catalog.py search --query '咖啡'
python3 scripts/reference_catalog.py search --mechanism '角色错位' --limit 20
python3 scripts/reference_catalog.py search --category '美妆与香氛' --collection 2026-11-05 --json
python3 scripts/reference_catalog.py search --curated --query '连衣裙' --json
python3 scripts/reference_catalog.py search --curated --limit 100 --json
```

关键词按空格分词，全部词都需命中。搜索范围包含标题、机制、动作、来源说明和商品接入假设。商品分类、机制和批次过滤可组合使用。JSON 输出供其他工具读取，目前尚未接入视频插件。

## 每条记录

| 字段 | 用途与填写依据 |
| --- | --- |
| `id / collection / category` | 稳定编号、收录批次、主要商品方向 |
| `source` | 原片或长期来源、平台、作者、查询时间和访问情况。`description_published_at` 是文章日期，与视频发布日期分别记录 |
| `media` | 来源封面、观看入口、可用播放地址、时长、画幅。未知填 `null` |
| `creative` | 可检索的机制、具体看点、开场与回报。来源说明整理须注明观察方式 |
| `actions` | 原道具、动作过程、实际观察的时间区间。未看视频时不填写虚构时间码 |
| `transfer` | 跨品类接入假设、必要改动及限制。`requires_product_review` 保持为真，通用线索不替代商品适配 |
| `depth` | `not_reviewed / usable / risky / unusable`，以及能保留、缺失的信息。候选阶段不预先转深度 |
| `observation` | `metadata_only / source_description / frames / partial_video / full_video`，实际观察范围与证据链接 |
| `prompt` | 原文、作者链接、中文改写、要点或未知。没有原文时不把创意拆解冒充原作者提示词 |
| `metrics` | 流量与成交分别记录。缺指标保持未知，作者热度不当作本次改编效果 |
| `experiment` | 实际使用结果或实验记录。未制作保持 `not_tested` |
| `review` | 分析日期、具体版本、声音依赖、使用判断及详情入口；`analyzed` 不表示已试生成 |
| `curation` | 精选100的阅读位置、入选原因、剧情/展示技法/条件参考标签、分类详解链接及复用标记。阅读顺序不是跨平台热度排名 |
| `links` | 观看、作者提示词、制作说明和实验入口 |

播放元数据接口返回成功，只能支持入口、封面、作者等字段；它不证明视频已完整观看，也不证明可以转载或成功复刻。来源可能失效，使用前重新核实当前访问情况。

### 2026-11-06新增100条的观察与提示词

[本批清单](../references/2026-11-06-creative-commerce-100.md)包含40条AI创作者作品和60条品牌广告与历史经典。初收录时40条AI作品均回查原帖公开正文与媒体，并各查看三张画面。当前本批共50条已进入精选100，升级为全片工具分析与逐秒画面复核；其余保留三点抽帧或来源说明级。未标为人工连续视听。风格偏离、片长不同、分镜板残留等情况按当前观察逐条更新。

作者正文中取得31条视频提示词、3条分镜图提示词、1条场景生图提示词。`prompt.stage`区分`video / storyboard_image / image`；`status = original_excerpt`仅表示保存了短摘录，完整公开原文链接回作者。`summary`与`summary_label`为本库中文整理。评论区只出现“提示词在下方”但未取得具体内容时，保留查询缺口，不按教程聚合页补成原作者原文。模型名称保存在`source.model_as_reported`，属于作者自述。

60条品牌广告初收录核对YouTube公开嵌入元数据与封面，动作依据剧情说明；进入精选的现按实际原片修正。`creator_role = video_uploader`不代表原创署名。片长若来自搜索卡片，标记`duration_basis = youtube_search_card_rounded`，取到原片后改为`retrieved_media_ffprobe`；上传日期未知时保持空，历史活动年份与文章日期另列。商品适配仍是未试验的编辑判断。

X互动快照保存浏览、点赞、收藏、回复等可见字段及查询日期，口径为帖子累计指标；不和其他平台混排，不推导增长率或成交。实际原片文件与抽帧只临时用于核对，公开仓库保留来源链接和观察信息。

### 全片辅助分析与逐秒复核

2026-11-06的20条记录使用完整链接调用Higgsfield视频分镜分析，再读取同一公开视频文件，以1fps按顺序复核开场到片尾。已发现工具对部分视频会压缩时间码、误认细节，不能直接把工具输出当作准确分镜；本库按原片逐秒画面重新整理中文动作，未复制原对白全文。

这些记录的 `observation.method` 保持 `frames`，不冒充人工连续视听。`visual_review` 保存全时长覆盖、采样数量、文件SHA-256和画面尺寸；音轨仅工具辅助识别，`audio_review = tool_assisted_only`。约1秒的时间区间用于点击定位，正式剪辑需要重新确认切点、接触时刻和拍点。临时原片与联系表不进入公开仓库。

`transfer.suitable_products` 记录可检索的商品类别、实例和适配原因；`replacement_steps` 给出具体换品动作，`example` 区分保留与新编。它们是编辑判断，不能替代本次商品的真实设计、尺寸、操作和功效资料。深度仍为 `not_reviewed`；动作保留项和缺口仅是RGB观察，不证明转换或生成成功。

本轮20条在已查作品简介、剧情和制作来源中均未找到原作者生成提示词，状态为 `not_found_in_checked_sources`，原文和提示词URL保持空，另列查询范围和来源。Old Spice经典片有公开广告脚本，单独记 `related_script_url`，不当作生成提示词。未发现不等于全网不存在。

## 收录顺序

1. **收线索。** 保存公开原链接、作者、封面及来源说明。优先有明确变化和观看回报的商品故事、展示方法与表演；普通口播和开箱可作为其他参考保留。
2. **观察原片。** 看开场、过程、结果和声音。按实际范围补 `observation`，给关键动作写时间区间，区分原片事实与联想假设。
3. **按本次商品匹配。** 检查原道具怎样被替换、哪一处能看清商品、多款色有哪些切换位置。商品关联、创意与深度可用性分别判断。
4. **选择后制作。** 选中原片后才裁切与转换深度。原片、提示词、参考图和深度各自承担的职责要清楚。
5. **回写结果。** 保存采用或放弃原因、实际动作和商品偏差、生成次数与实验记录。否定原因有助于后续少推荐同类不合适作品。

为减少重复，优先以真实播放地址识别同一作品；X 的账号别名、跟踪参数和 YouTube 短链会规范化。同一教程页有多个真实视频时，分别使用各自媒体地址。不同上传版本仍需人工核对是否为同一内容。

## 飞书入口

仓库中的收录脚本会在保存群分享 Markdown 时，同时加入结构化记录并重建首页与索引。公开嵌入正文只作为 `metadata_only` 线索进入“通用商品与品牌”，后续再补分类、机制与视频观察，避免自动把文案当画面事实。

程序重启后使用更新代码。既有运行进程与凭证按原部署管理。此库只发布公开来源与整理信息，第三方完整原片、人物声音和派生深度不随数据自动转载。
