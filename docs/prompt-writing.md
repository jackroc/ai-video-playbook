# 视频提示词怎么写

本页是可测试的写作起点，具体效果以模型和实测为准。平台的时长、参考图、音频和负面提示词能力应在实际生成时核对，并记录在实验中。

## 先给素材角色，再写镜头

给每份输入明确用途，例如：`PRODUCT_REF` 是商品外观依据，`ACTOR_REF` 是人物身份依据，`SCENE_REF` 是场景依据。它们是本库的文字占位符，不是任何平台的特殊语法；操作时必须绑定真实素材。

商品信息不足时，先补齐外观、尺寸、变体和用法。提示词中的「严格一致」只是要求，成片仍需逐帧检查。

## 一个镜头的写作骨架

```text
目的：这一镜让观众看见什么？
输入依据：人物、商品、场景分别参考哪份素材？
画面：景别、机位、光线和风格。
主体：谁在哪里，商品放在哪里，有多大？
动作：按先后顺序描述一个主要动作及其可见结果。
镜头运动：固定 / 轻微手持 / 单次推进，按需要选择。
表演：视线、表情、停顿和情绪变化。
声音：原声、环境声、对白；注明是否改为后期配音。
结束状态：人物、手、商品的位置，为下一镜留下什么画面。
约束：必须保持的外观，以及本镜头具体要避免的问题。
```

## 示例：把抽象形容词变成可见动作

较难执行：`生成一个高级、真实、爆款、很有说服力的理线器广告。`

可测试版本：

```text
竖屏，手机随手拍的桌面近景，柔和窗光，固定机位。
商品外观依据 PRODUCT_REF，保持实际颜色、形状和尺寸比例。
桌面上有两根分开的充电线，成人右手拿起其中一根，
按真实用法将它放入理线器的一个槽位，再松开手。
结尾保持两秒，让观众看到线停留在槽位中。
一镜只完成这一个操作。不要生成文字、额外商品或瞬移。
```

假如实物不是槽式理线器，这段动作就不能直接使用，应按产品实际结构改写。

## 分开写脚本与生成提示词

脚本负责「为什么看下去」：开头冲突、商品作用、结尾回扣。生成提示词负责「镜头里发生什么」：人物、道具、动作、机位、结束状态。用时间段标出叙事节拍，平台单段时长不足时拆成多个片段，最终在后期完成节奏。

较长口播可先单独生成画面，再制作配音和字幕。需要嘴部入镜时，使用实际支持的口型工作流并验收，不要把同步成功当成默认结果。

## 约束要与镜头问题对应

- 商品：固定变体、包装结构、标志位置；不自动增加配件。
- 人物：固定参考身份、服装和发型；确认各镜头可持续一致。
- 动作：指定哪只手、接触点和结束位置；复杂操作拆成插入镜头。
- 画面文字：包装文字无法准确生成时，使用真实商品图或后期合成；字幕后期添加。
- 物理：先展示真实功能；超现实笑点在单独镜头中完成。

负面提示词只在平台支持时使用；也应将关键要求写进正向描述。每次只改变一个主要变量，保留所有原始版本，避免无法判断究竟是什么带来了改善。
